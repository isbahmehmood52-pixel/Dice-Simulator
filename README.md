# Dice-Simulator
🎲 Dice Simulator (Python)

A simple, interactive, and customizable Dice Simulator built using Python. Perfect for tabletop games, decision-making, or quick random number generation!

✨ Features

🎲 Single & Multiple Dice: Roll one or multiple dice simultaneously.

⚙️ Custom Die Sides: Choose standard 6-sided dice (D6) or RPG-style dice (D4, D8, D10, D12, D20, D100).

📊 Roll History & Totals: Displays individual dice results, sum of rolls, and previous roll history.

🎨 Visual ASCII / GUI Representation: Shows visual dice faces or a clean GUI/CLI output.

⚡ Instant & Fair: Uses Python's cryptographic/pseudo-random module to ensure fair outcomes.

🛠️ Built With

Python 3.x - Core application logic and random number generation.

Random Module - Built-in standard library for generating unbiased dice rolls.

(Optional) Tkinter / Pygame - For GUI representation (if applicable).

🚀 Getting Started

Prerequisites

Make sure you have Python 3.x installed on your system. You can check by running:

python --version


Installation & Execution

Clone the Repository:

git clone https://github.com/YOUR-USERNAME/Dice-Simulator.git
cd Dice-Simulator


Run the Script:

python main.py


(Replace main.py with your script name like dice_simulator.py if different).

🕹️ How to Use

Launch the application.

Select the number of dice you want to roll.

Choose the number of sides for the dice (e.g., 6 for standard D6).

Press Enter or click Roll to generate the outcome.

View individual face values and the combined total score!
